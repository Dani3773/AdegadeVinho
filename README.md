
🇧🇷 Português

Aplicativo Android para gestão de adega: clientes, representantes, vinhos e pedidos — com emissão e relatórios simples.
Projeto acadêmico evoluído para portfólio profissional.

Funcionalidades

Login (Administrador e Representante)
Cadastro, edição e exclusão de clientes
Gerenciamento de representantes
Catálogo de vinhos (SQLite + integração futura com API via Retrofit)
Emissão e listagem de pedidos
Cadastro e acompanhamento de metas
Relatórios de vendas
Tela de contato

Tecnologias

Android Studio (Java)
SQLite Database
Retrofit2 (cliente HTTP)
RecyclerView + Adapters
Material Design Components

Estrutura Simplificada
app/src/main/java/com/example/adegadevinho/
├─ MainActivity.java
├─ LoginActivity.java
├─ AdministradorActivity.java
├─ RepresentanteActivity.java
├─ DatabaseHelper.java
├─ Sessao.java • Usuario.java
├─ Clientes/Representantes/Vinhos/Pedidos/Metas (Activities e Adapters)
├─ RetrofitInstance.java • VinhoApi.java • VinhoService.java
└─ adapters/
